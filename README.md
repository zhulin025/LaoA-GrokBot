一个可定制、可随机组合并生成分享卡的 GrokBot 表情动作实验室。

## 功能

- 10 种颜色、8 种形状、25 套表情与 39 种状态
- 身体部件、配饰与 6 种果冻感快捷动作
- 生成 1080×1440 PNG 分享卡
- 直接打开 X 发布页，并预填 GrokBot 文案、网页地址和 GitHub 仓库地址
- 下载 PNG 分享卡后可手动添加到 X 帖子

## 本地运行

```bash
python3 -m http.server 4173
```

访问 `http://127.0.0.1:4173/`。

## 隐私

所有定制与图片生成均在浏览器本地完成，不上传用户数据。
